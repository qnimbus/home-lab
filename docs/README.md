# Documentation Index

This folder holds the home-lab cluster's documentation. Each doc has a **primary audience** and a
**status** — use this index to find the right document and to know how much to trust it.

## Legend

| Symbol | Audience | Meaning |
|--------|----------|---------|
| 🤖 | **Agent** | Written for the Claude Code agent — operating rules or recall knowledge. Humans may read it, but its job is to steer the LLM. |
| 👤 | **Human** | Written for a human operator — onboarding, current-state reference, runbooks, planning. |
| 🗄️ | **History** | Closed/abandoned topic kept for posterity. Not current; do not act on it as live guidance. |

| Status | Meaning |
|--------|---------|
| 🟢 Living | Actively maintained; reflects current reality. |
| 📐 Planning | Forward-looking design or backlog; not yet built. |
| 🗄️ Archived | Closed topic, retained for reference only. |

## Source-of-truth map (avoid duplicating these facts)

When a fact appears in more than one doc, **one doc owns it** and the others should *link*, not copy.
This prevents the independent drift that this index exists to fight.

| Fact | Owner (edit here) | Others link / summarise |
|------|-------------------|-------------------------|
| Current hardware, NIC topology, disk inventory | **CLUSTER.md** | CLAUDE.md keeps a 3-line node/IP table + link |
| Networks / subnets (current) | **CLUSTER.md** | CLAUDE.md keeps a compact CIDR table |
| What is deployed (live inventory) | **REPO-AUDIT.md** + **CLUSTER.md** | POTENTIAL-DEPLOYMENTS ✅ markers are a lagging snapshot |
| Failure modes, blast radius, DR/recovery status per component | **RESILIENCE-AUDIT.md** | CLUSTER.md/QA.md own the actual runbook steps — RESILIENCE-AUDIT links to them, doesn't copy them |
| Chart / component versions | the Renovate-tracked `helm/values.yaml` & `talenv.yaml` | docs may quote but will drift — prefer "tracked by Renovate" |
| Planned storage (Rook-Ceph, 5-node) | **HARDWARE-ARCHITECTURE.md** | ROADMAP's *Rook-Ceph Migration* item links here |
| Agent operating rules | **CLAUDE.md** (+ CONVENTIONS.md for detail) | other docs link to the relevant section |

> **Maintenance:** when you add or retire a doc, add/remove its row here and in the section tables
> above. When you find the same fact in two docs, decide an owner and replace the copy with a link.
